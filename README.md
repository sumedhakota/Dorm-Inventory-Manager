# Dorm-Inventory-Manager
This is a Java program that helps students plan and organize all their items that they need for their dorm. 

## The Problem
Living in a dorm meand keeping track of belongings in a limited amount of space, so it can be difficult to remember
where different items are stored. This program will help organize that.


## MVP Scope
- add items with a name, category, and location
- remove items from their inventory
- view all items
- search for specific items
- save inventory information


## Tech Stack
- language: java
- libraries: ArrayList, Scanner, FileReader, FileWriter
- tools: terminal and gitHub
- data storage: text file

## Future Plans
- track quantity of each item
- create shopping list
- track item prices
- sort by category
