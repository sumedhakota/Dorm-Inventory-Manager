# Dorm-Inventory-Manager
This is a Java program that helps students plan and organize all their items that they need for their dorm. 

## The Problem
Living in a dorm means keeping track of belongings in a limited amount of space, so it can be difficult to remember
where different items are stored. This program will help organize that.


## MVP Scope
- Add items with a name, category, location, and quantity
- Remove items from the inventory
- View all items
- Search for specific items
- Save and load inventory information


## How It Works
When the program starts, it loads previously saved
inventory information from a text file. The user is then prompted to choose an option from the menu that consists of choices that add, view, remove, or search for items. Each item includes a name, category, location, and quantity. The menu continues to appear until the user presses the option to exit. When exiting, the program saves all the inventory information to a text file so that it can be accessed the next time the program is run.


## Tech Stack
- Language: Java
- Libraries: ArrayList, Scanner, BufferedReader, PrintWriter
- Tools: VS Code, Terminal, GitHub
- Data Storage: Text file
